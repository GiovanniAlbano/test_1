Benvenuto in test_1

Questo progetto è un semplice programma Python da riga di comando: stampa un saluto e, se vuoi, può personalizzarlo con un nome.

Come funziona

Senza argomenti, il programma saluta il mondo. Passandogli un nome, usa quel nome nel messaggio.

Avvio

Apri un terminale nella cartella del progetto ed esegui:

python main.py
python main.py Giovanni

Il primo comando stampa Hello, World!; il secondo stampa Hello, Giovanni!.

Test

Per eseguire i test automatici, usa:

python -m unittest discover -s tests -v
